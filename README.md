# ezzfolio

A gallery of my creative work: posters, jackets, zines and a few side projects.

- `npm run dev` / `npm run build`
- Add images to `public/assets/work/<folder>/` (full `name.webp` + `name_thumb.webp`), then run `node manifest.mjs` to regenerate `src/data/work.json`. Series, order and blurbs are configured at the top of `manifest.mjs`.
